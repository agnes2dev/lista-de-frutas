# lista-de-frutas
Lista de compras de supermercado feita em Python

Esse exercício consiste em todos os conceitos básicos de programação utilizados separadamente nas files do meu repositório "Python 1", agora utilizados para construir um programa interativo que simula uma cesta de compras de supermercado, implementando:

Funcionalidades Principais:

- CRUD completo (Create, Read, Update, Delete)
- Adição/remoção de itens via input do usuário
- Verificação e alteração de itens existentes

Técnicas Implementadas:

- Estruturas de dados: Listas (frutas = [])
- Controle de fluxo: Loops while aninhados
- Tratamento de erros: try-except para inputs inválidos
- Modularização: Funções dedicadas para cada operação
- Interface textual: Menu interativo com múltiplas opções

Objetivo de Aprendizado:
- Consolidação dos fundamentos de Python:
- Variáveis e estruturas de dados
- Estruturas condicionais e de repetição
- Funções e escopo de variáveis
- Manipulação de listas (append/remove)
- Validação de entrada do usuário
